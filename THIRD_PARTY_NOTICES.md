# Third-Party Notices

This project installs Electron and electron-builder through npm when the Windows launcher is used. Their licenses and transitive dependency notices are available in the installed `node_modules` tree and generated package output.

Provider runtimes, APIs, installers, and services remain separate products governed by their own licenses, terms, quotas, and privacy policies:

- OpenAI Codex CLI (`@openai/codex`)
- Google Gemini Developer API
- Ollama for Windows and local Ollama models
- Google Antigravity (manual handoff only)

No provider binary or model is redistributed inside this source ZIP. Noor AI Studio downloads or opens official provider resources during user-initiated setup.
